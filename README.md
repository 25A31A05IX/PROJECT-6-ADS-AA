# 🌍 Climate Time-Series Sorting and Ranking

📌 Project Overview

Climate Time-Series Sorting and Ranking is a C++ based project developed as part of the Advanced Data Structures (ADS) course.

The project focuses on sorting and analyzing climate records such as temperature and precipitation using two important sorting algorithms: Quick Sort and Merge Sort.

It helps organize climate data, identify extreme weather conditions, and compare the performance of different sorting algorithms.

🎯 Objectives

- To implement Quick Sort and Merge Sort algorithms using C++.
- To organize climate records based on temperature and precipitation.
- To identify the highest and lowest temperature records.
- To rank climate records and identify extreme weather events.
- To compare the execution time of both sorting algorithms.
- To understand Divide and Conquer techniques.
- To analyze the time complexity of sorting algorithms.

⚙️ Key Features

🧠 Algorithms Implemented

1. Quick Sort

Quick Sort is a Divide and Conquer sorting algorithm that selects a pivot element and partitions the array into smaller sections.

Time Complexity:

- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n²)

2. Merge Sort

Merge Sort is a Divide and Conquer algorithm that divides the dataset into smaller parts, sorts them, and merges them into a sorted sequence.

Time Complexity:

- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n log n)
